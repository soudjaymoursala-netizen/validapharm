# Connecteurs

Implémentations des contrats d'interface : Git (SDS §5), Drive (SDS §5bis), IA — `ProviderAdapter` (SDS §6), QMS tiers — `QMSConnectorAdapter` (SDS §6bis). Chaque connecteur lève des exceptions typées distinctes (jamais une exception générique) — voir SDS pour le contrat d'erreur de chacun.
